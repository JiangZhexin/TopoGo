# 拓扑模型（TOPOLOGY_VERSION = topo-v1）

## 独立落点与坐标

N=19（亦支持 9/13），`V = {(x,y): 0<=x,y<N}`，`id(x,y)=y*N+x`。x 向右、y 向下。
「19×19」= 361 个独立落点；切口在落点之外，**不做任何顶点合并**（首尾列不合并、对径点不合并）。
界面显示坐标 A–T（跳过 I）与 19–1，仅作显示，内部一律用 vertexId。

## 统一跨边邻接约定

内部四方向按普通矩形网格；越界时按下表（翻转为 `N-1-coordinate`）：

| topologyId | 向左越界 | 向右越界 | 向上越界 | 向下越界 |
|---|---|---|---|---|
| plane | 无 | 无 | 无 | 无 |
| torus | (N-1,y) | (0,y) | (x,N-1) | (x,0) |
| mobius | (N-1,N-1-y) | (0,N-1-y) | 无 | 无 |
| klein | (N-1,N-1-y) | (0,N-1-y) | (x,N-1) | (x,0) |
| projective | (N-1,N-1-y) | (0,N-1-y) | (N-1-x,N-1) | (N-1-x,0) |

环面零组反向、克莱因瓶一组反向、RP² 两组反向。
`neighbors(v)` 去重、无自环、无向对称；规则层只用去重集合，UI 的有向接缝记录另行保留。

## RP² 角点

N=19 时 `(0,0)` 向左与向上均到达 `(18,18)`，故 `neighbors(0,0) = {(1,0),(0,1),(18,18)}`。
四角各 3 个邻点，其余 357 点各 4 个。两条跨缝路径通向同一空点只提供一口气。
这是闭曲面上离散模型在四角的局部度数变化，不是「有边界」：四价全四边形闭胞腔分解必有 χ=0，而 RP² 的 χ=1，二者不可兼得。

## 显式面数据与验证

生成四边形面列表 F（内部面、周期/翻转接缝面、环面与克莱因瓶的额外角面；RP² 不加角面），
validator 从实际结构计算：每条边的面关联数、顶点 link 单圈/单路径、可定向性、边界分支、度数直方图、Euler 数。
