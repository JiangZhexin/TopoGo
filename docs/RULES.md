# TopoGo Area v1 规则合同

基于图连通性的面积计分，参考 Tromp–Taylor 的简洁定义，明确修改为禁止自杀，并加入适合同机玩家的终局协商流程。本规则是本项目的设计决定，不代表某种公认的「拓扑围棋官方规则」。

## 固定规则

- 黑先白后；不设让子；默认白贴 7.5 分（新建游戏时可改）。开局后贴目与拓扑不可修改。
- 每步落在空顶点；**先提掉无气的对方棋串，再检查自己的棋串是否有气**。
- 禁止自杀；不能因落点起初被包围就直接禁止能提子的着法。
- **positional superko（PSK）**：一次实际落子后的完整棋子分布不得与当前有效对局历史中的任何局面相同（含初始空盘）。
- 停着永远合法（不受 PSK 限制），记录停着与轮次；无 pass-stone 额外分数。
- 两次连续停着进入终局协商，不直接宣告胜负。
- 认输需界面确认，随后立即按认输结局结束。

## 棋串与气

- 棋串 = 同色石子在图上的最大连通分量（跨缝相连算同一串）。
- `liberties(C) = { v : 空 且 存在 u∈C 使 v∈neighbors(u) }`——气是集合：两条不同跨缝路径通向同一空点只算一口气（RP² 四角即如此）。

## applyMove 事务顺序

1. 拒绝非法阶段、越界、已占位置；
2. 副本试下 → 收集相邻不同对方棋串，提掉零气串 → 重算己串气，为零则整步撤销（自杀）；
3. 局面键与有效历史重复则整步撤销（PSK）；
4. 通过后提交棋盘、提子记录、轮次、历史、手数、lastMove，连续停着归零。

非法操作不改变任何状态，也不重置连续停着数。

## 历史与 PSK

- 局面键 = `topologyVersion | N | 361 位颜色序列`（固定 vertexId 顺序）。
- 不把 toPlay 加入键（否则变 SSK）；不做旋转/平移/镜像/图自同构归一化；拖动视图不改变真实棋盘或键。
- 悔棋后从有效历史前缀重建键集合；停着产生的重复键按 Map<key,count> 计数处理（实现以 positionKeys 数组 + 游标截断表达同等语义）。

## 游戏状态机

`setup -> playing -> scoring -> finished`

- 两次连续停着：playing -> scoring。保留未移除死子的真实棋盘快照与 nextToPlay（第一次停着的玩家）。
- scoring 中点击棋子切换整串 proposedDead（只改预览）；黑白分别确认同一 revision；任何标记变化清除两人确认；双方确认同一版本后结算进入 finished。
- 任何一方可恢复对弈：清除标记与确认，恢复快照棋盘与 nextToPlay，连续停着归零；预览中的死子不会被永久移除。
- 未达成一致时不允许以估值强行判胜。

## 终局面积计分（确定性裁判）

确认死子集合 D 从棋盘副本移除；保留黑、白石子数 B、W；剩余空点按真实图邻接 flood fill：

- 空连通分量 R 仅邻黑 → |R| 计入 TB；仅邻白 → TW；邻两色或无邻子 → 中立 U。
- `SB = B + TB`，`SW = W + TW + komi`，`margin = SB - SW`（正黑胜，负白胜，零和棋）。
- 每次算分断言 `B + W + TB + TW + U = N²`。
- 提子计数仅过程展示，不额外加分；确认移除的死子不再当俘虏重复计分。
- 双活不自动删除；混合边界的公共气中立；单色边界的私有空点依算法计入面积（不套用日式「整块双活不计地」例外）。
- **拓扑原则**：计分判断空点的图连通分量，不凭 2D 图上是否画出闭合圈。环面上绕一圈的棋串未必围出分离区域（见 tests/scoring.test.ts 的 152+171 中立示例）。
