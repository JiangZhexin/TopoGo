# 已知限制（V1）

## 规则与裁判

- **死子不会自动判定**：终局死子标记完全由双方协商；程序不替任何一方认定死活，未达成一致时不强行判胜（可恢复对弈实际提掉争议棋）。
- **双活不自动删除**；混合边界公共气中立；单色边界私有空点按算法计入面积（不套用日式例外）。
- 7.5 贴目是原型默认参数，**不宣称对任何拓扑公平**。
- 棋谱 JSON 为本项目权威格式；SGF 暂未支持（自定义拓扑需要非标准属性，留作后续扩展）。

## 局势辅助

- **势力图（启发式）** 是离散调和方程的解：不处理死活、劫争与最佳对抗，不能用于裁定终局。仅一色落子时解退化，界面明确提示「仅反映影响」。
- **参考估值** = `B-W+Σh-komi` 的势力折算差，不是预言终局分差，没有置信区间与胜率；早盘与仅一色时弱化显示。
- 二气警示不等于必死；一手提子点列表不含义最佳着法。
- V1 不含 Monte Carlo / MCTS（规划在 V2，届时固定种子与模拟数保证可复现）。
- **不套用普通 KataGo 权重**：本棋盘的跨边邻接与普通棋盘不是同一环境，未经环境改造与重训练的权重不适用。

## 交互与平台

- 同机双人轮流操作；无账号、无联网对战、无后端。局域网对战属后续增强。
- 幽灵副本为显示辅助：状态、历史与分数只按 canonical vertexId 存一次。莫比乌斯/克莱因/RP² 的角落幽灵格因翻转映射歧义不绘制（边带正常）。
- V1 无 3D 视图；RP² 使用展开图 + 接缝提示（3D 浸入示意为后续项）。
- SVG 棋盘在测试机器上交互流畅；不承诺所有机器固定帧率。势力计算在 Web Worker 中执行，UI 保持可操作；无 Worker 环境退化为同步计算（可能短暂占用界面线程）。

## 测试覆盖声明

- Vitest：62 个测试覆盖拓扑不变量（N=5/9/13/19）、规则（含 RP² 角点夹具、单劫 PSK）、计分（含环面 152+171 中立示例）、历史/协商、评估与 IO 往返。
- Playwright 浏览器流程测试：**未运行**（脚手架见 e2e/README）。不伪造绿灯。
- 性能目标（落子与提示约 100ms 内）为验收目标，未在所有目标机器实测。
